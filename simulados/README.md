# Simulados

[Voltar ao início](../README.md)

Esta pasta receberá registros de simulados. Ainda não há simulados realizados ou resultados registrados.

## Registro sugerido

Crie um arquivo `aaaa_mm_dd_<identificacao>.md` para cada simulado e informe:

- Fonte e questões utilizadas.
- Tempo previsto e tempo utilizado.
- Quantidade de questões, acertos, erros e questões em branco.
- Dificuldades encontradas e motivo dos erros.
- Links para as resoluções em `questoes/`.
- Assuntos que precisam de revisão.
